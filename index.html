About Me

I am currently working as a Fullstack Developer in the banking industry, where security and high performance are paramount. In this role, I actively develop and maintain mission-critical applications using Angular and Java Spring Boot, while leveraging tools like GitLab, Jira, and Confluence for CI/CD and agile project management. Prior to this role, I spent several years developing enterprise-grade systems for warehouse management, retail, and port logistics.

Bringing 4 years of comprehensive software engineering experience, my core expertise also includes crafting robust solutions using Flutter, React Native, Node.js, and SQL/NoSQL databases, frequently implementing secure offline-first architectures for various environments. Beyond enterprise projects, I actively develop innovative independent applications such as community management platforms and personal finance tools utilizing modern tech stacks like Supabase, Firebase, and local databases (Drift/SQLite). I am committed to continuous learning and delivering high-quality technology solutions that create tangible value for users and businesses alike.
